# Online Examination System using Java

## 📌 Project Title

Online Examination System using Java

---

## 📖 Project Description

The Online Examination System is a Java-based desktop application developed using Java Swing for conducting online examinations digitally. The project helps students attend examinations easily while enabling automatic evaluation and score generation.

Traditional examination systems require manual paper correction and consume more time. This project provides a faster, reliable, and user-friendly solution by automating the examination process.

The application is developed using Object-Oriented Programming concepts and includes graphical user interface components for better user interaction.

---

## 🎯 Objectives

* To develop an online examination system
* To reduce manual correction work
* To provide automatic result generation
* To improve examination efficiency
* To save time and reduce errors
